# 更新履歴の下書きを作る

1. 対象リポジトリと比較元のタグ・コミットを確認する。指定がなく一意に決められない場合は利用者に確認する
2. git log で、比較元から現在の対象コミットまでの変更を一覧にする
3. 利用者に関係する変更だけを選び、「追加」「変更」「修正」に分ける
4. 1項目1行で、利用者から見た変化を書く
5. CHANGELOG.md は書き換えず、下書きを返答に出す
